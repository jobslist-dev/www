Was dieses Assessment bewertet

Die Fragen decken diese Bereiche ab, mit einer Fähigkeit pro Frage – so sagt Ihnen eine falsche Antwort etwas Konkretes, statt nur die Punktzahl zu senken.

SQL-Tiefe
Window-Funktionen, Aggregation und Abfragen, die korrekt bleiben, während die Daten wachsen.
Pipeline-Design
Idempotenz, Backfills, späte Daten und Wiederholungsläufe, die nicht duplizieren.
Datenmodellierung
Granularität, Schlüssel und bewusst gewählte Slowly Changing Dimensions.
Datenqualität
Falsche Daten erkennen, bevor ein Dashboard sie selbstbewusst meldet.
Batch und Streaming
Was eine Anforderung wirklich braucht – und die Kosten der falschen Antwort.

Wie die Fragen aussehen

Fast jede Frage stützt sich auf bereitgestellten Code, einen beschriebenen Vorfall oder eine konkrete Situation, sodass sie sich nicht allein aus der Frage beantworten lässt. In der Praxis bedeutet das etwa Folgendes:

  • •Eine Abfrage lesen und sagen, was sie für gegebene Zeilen zurückgibt.
  • •Bei einer Pipeline, die nach einem Wiederholungslauf doppelt gezählt hat, die Ursache identifizieren.
  • •Eine Tabellengranularität für eine genannte Reporting-Anforderung wählen.
  • •Zwischen Batch und Streaming unter einer Latenzvorgabe entscheiden.

Wir veröffentlichen die Form der Fragen, nicht den Fragenpool selbst – echte Fragestellungen, Antworten und Bewertungsraster bleiben auf dem Server, damit das Assessment weiter funktioniert. Bei den Fragen geht es darum, Code zu lesen und zu beurteilen, nicht ihn auszuführen.

Wenn Sie dieses Assessment ablegen

Sie sehen die Anzahl der Fragen, das Zeitlimit, die Themen und wer fragt, bevor Sie beginnen. Die Uhr startet, wenn Sie auf Start drücken. Sie können jede Antwort ändern, bis Sie absenden, und jede Antwort wird fortlaufend gespeichert – bei einem Neuladen oder einer unterbrochenen Verbindung geht nichts verloren.

Was wir nicht tun

  • Keine Webcam. Es wird nichts gefilmt.
  • Keine Bildschirmaufzeichnung und keine Fernsteuerung des Rechners des Kandidaten.
  • Keine Browser-Sperre und keine Strafe für das Wechseln von Tabs.
  • Keine automatischen Anschuldigungen – ein Mensch entscheidet, niemals ein Schwellenwert.

Was wir stattdessen tun

  • Jeder Kandidat erhält eine andere Auswahl an Fragen aus einem deutlich größeren Pool.
  • Die Zeit wird vom Server gehalten, sodass sich die Uhr nicht im Browser manipulieren lässt.
  • Einladungslinks sind einmalig nutzbar und laufen ab.
  • Die Fragen sind um bereitgestellten Code und konkrete Situationen herum gebaut, nicht um Wissen, das man nachschlagen kann.

Wenn Sie fertig sind, können Sie ein kostenloses JobsList-Profil beanspruchen und Ihr Ergebnis behalten, um es bei künftigen Bewerbungen wiederzuverwenden. Kostenloses Profil erstellen.
